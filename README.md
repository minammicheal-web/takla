Takla Ibrahim pharmacy inventory app: medicines with strength/form, expiry dates and batches, purchases, sales, returns, suppliers, customer debts, receipts, barcode scanning, users and two-phone sync, in Arabic and English.

Every push to main builds Takla.apk and publishes it under Releases.

The same push also builds Takla-Setup.exe, the Windows 10/11 version (folder `desktop/`), and adds it to the same release.
